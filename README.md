## Quick GitHub Pages Deployment (Drag-and-Drop)
1. Extract `Khushie-V3-Final-Complete.zip` on your laptop.
2. Drag and drop all extracted files (`index.html`, `404.html`, `dist/`, `public/`, `src/`, `package.json`, etc.) into your GitHub repository root.
3. Enable **Settings → Pages → Deploy from branch (`main` / `/ (root)`)**.
